RIBBIT RACE FRIENDS — ONLINE, REPLAY, LANGUAGE, HATS, AND UI POLISH 8
Build: 2026.10.12-friends-polish-8
Displayed version: VERSION 1.7.10

REPLAY AND LEADERBOARD
1. Replaced the broken World Record HTML-video popup with the in-game replay player.
2. Added a canvas-native Leaderboard screen styled like Frog Tags.
3. Added a small gold-medal Leaderboard button to the lower-left corner of Achievements.
4. Added replay-video buttons to leaderboard rows that contain replay data.
5. Significant solo records and personal bests now attempt to archive and upload their replay automatically.
6. Online matches now attempt to archive a replay at match completion.
7. Frog Tags history merges locally archived online matches and exposes replay playback where a replay ID exists.
8. Added an end-of-round New World Record card with prior-holder, date, and prior-value hover details.
9. Fly labels now fade back in after the final-catch slow-motion camera rather than appearing in one frame.

ONLINE AND QUICKPLAY
10. Reordered the online menu to Quickplay/Spectate, Host/Join, and Customizer/Frog Tags.
11. The complete online header now uses the selected frog's palette instead of a split-color header.
12. Rebuilt online hover help as compact speech bubbles directly above the hovered button.
13. Quickplay no longer displays a menu-state pause button or Player 2 badge.
14. Quickplay Back uses the same position as the preceding online menu.
15. Quickplay spacing was revised so queue instructions and status text remain readable.
16. Leaving Quickplay cancels the stale queue/room immediately so the player can requeue without waiting for the former match to finish.
17. Mobile Quickplay can use Home from Pause.
18. Versus shows Pause only during an active match, beneath the Player 2 score, using the Single Player visual design.
19. The countdown immediately switches the resumed control back to the pause-bars icon.
20. The CPU/Local Versus hover now displays one centered speech bubble and changes its instruction after Local Versus is enabled.

MAIN MENU AND ACCOUNT UI
21. Rebuilt Profile, device, Achievements, and Stats hover help as readable black-text speech bubbles.
22. Corrected profile/account modal contrast, including the final option.
23. The hand cursor now appears only over genuinely interactive canvas controls.
24. Removed the floating lower-right Fullscreen button and added Fullscreen to Pause.
25. Pressing R or Escape during a run clears flies and tongue state and restores the starting position immediately instead of showing a frozen previous run during a countdown.

HATS AND ACHIEVEMENTS
26. Correct catches now update per-skin hat progress immediately, including Azure progress toward Top Hat.
27. Hat progress is mirrored into the existing statistics profile and reevaluated after each correct catch.
28. Unlocks can produce the normal unlock/achievement feedback without requiring a menu reload.
29. Clicking a locked hat no longer pins its requirement text indefinitely.
30. Hovering an unlocked hat can still explain the condition that originally unlocked it.
31. Ember's total-flies progress line is hidden once Ember is unlocked.
32. Tutorial activity remains excluded from normal achievement and hat-progress earning.

LANGUAGE PREFERENCES
33. Account creation now asks for the language the player speaks and the language being learned.
34. Added English-to-Spanish and Spanish-to-English modes.
35. Spanish-to-English reverses fly terms and clues and localizes core menu/instruction labels into Spanish.
36. Language preferences can be edited from the Profile button.
37. Online players and spectators render fly language locally from their own preference, while the shared match state remains language-neutral.

CUSTOM FROG AND ICONS
38. Updated favicon, browser-tab icon, and installable app icons with the supplied frog artwork.
39. Removed the large Base Palette copy panel from the custom-frog screen.
40. Added a Set Base control inside the custom-frog preview so a default frog can seed the custom palette.
41. Pasting a palette now preserves the custom-frog menu instead of returning to the main menu.

DEPLOYMENT
No Apps Script or code.gs update is required.
Keep the current Cloudflare bindings, replace the repository root contents with this package, then run:

npm install
npm run check
npm test
npx wrangler deploy

After deployment, hard-refresh desktop browsers and fully close/reopen installed mobile Home Screen versions.
