# Friends Edition hat requirements

Progress begins only after the Hats feature is unlocked in build 1.4.1. Existing totals become the baseline and do not grant hats retroactively.

| Hat theme | Requirement after Hats unlock |
|---|---|
| Flower / Bloom | Finish Garden in under 30 seconds while using Bloom/Blossom |
| Bunny ears | Rebound from a human frog 10 times in Versus |
| Crown | Win 10 individual Versus matches |
| Top hat / academic | Catch 75 flies |
| Party hat | Earn 5 new achievements |
| Straw / sun hat | Finish Park in under 25 seconds |
| Pirate | Win 5 online matches |
| Wizard / witch | Win 3 Random-mode runs |
| Cowboy | Complete 25 jumps |
| Horns / devil | Bonk a human frog 10 times |
| Chef | Catch 100 flies |
| Antenna / bug | Catch 150 flies |
| Halo / angel | Win on all six levels |
| Baseball cap | Win Park 5 times |
| Sombrero | Win Garden 5 times |
| Santa / winter | Win Lake 5 times |
| Glasses / scholar | Earn 5 new achievements |
| Bow / ribbon | Win Pond 3 times |
| Propeller / pilot | Complete 50 jumps |
| Any additional catalog hat | Catch 40 flies |

The fallback ensures every hat in the live catalog has a post-unlock requirement even when a future hat ID is added without a dedicated rule.
