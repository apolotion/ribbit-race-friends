# Friends Edition hat requirements

Progress begins only after the Hats feature is unlocked in build 1.6.0. Existing totals become the baseline and do not grant hats retroactively. Typing `hatstest` exposes the Hats feature for testing but does not unlock a hat.

No requirement below depends on an online opponent or a human opponent.

| Hat theme | Requirement after Hats unlock |
|---|---|
| Flower / Bloom | Finish Garden under 30 seconds as Blossom |
| Bunny ears | Finish Pond under 30 seconds as Silver |
| Crown | Win 10 Versus matches |
| Top hat / academic | Catch 75 flies as Azure |
| Party hat | Catch 50 flies as Plum |
| Straw / sun hat | Finish Park under 25 seconds as Forest |
| Pirate | Win Lake 3 times as Azure |
| Wizard / witch | Win 3 Random runs and at least one level as Violet |
| Cowboy | Complete 50 jumps as Ember |
| Viking / horns / danger | Win 5 Versus matches as Ember |
| Chef / cook / taco | Catch 100 flies as Crimson |
| Antenna / bug / leaf / lily | Catch 125 flies as Forest |
| Halo / angel / nurse | Win all 6 levels as Silver |
| Baseball cap | Win Park 5 times as Azure |
| Sombrero / flamenco | Win Garden 5 times as Crimson |
| Santa / beanie / sleep | Win Lake 5 times as Silver |
| Bow / ribbon / beret | Win Pond 3 times as Blossom |
| Propeller / headphones / headband | Complete 100 jumps as Violet |
| Hard hat / miner / fireman / police | Win Jungle 3 times as Forest |
| Any additional catalog hat | Catch 40 flies as Azure |

The fallback rule ensures a future catalog hat still receives a post-unlock challenge instead of becoming immediately available.
