WHAT EXECUTED
The distributed game HTML, hub, room lifecycle, save helpers, routing and
WebSocket relay code ran in the tests. Node 22.16.0 used an in-memory SQLite
adapter for the Cloudflare storage interface. HTTP requests and actual local
WebSocket connections reached that code through a local Node HTTP/upgrade adapter.
Chromium ran the real DOM/canvas game; test-only shims supplied storage and
forwarded browser HTTP/WebSocket traffic through Python to the local adapter.
Those shims and developer control hooks are not present in the released game.

The unit tests are included in tests/core.test.mjs. Run npm test.
The HTTP smoke test is included in scripts/smoke.mjs. Run npm run smoke -- YOUR_URL
only against your own deployment; it creates and deletes a temporary account.
The local browser/Cloudflare adapters are environment-specific test harnesses,
not production server alternatives, and are not distributed as the runtime.

NOT VERIFIED / NOT A GUARANTEE
- Native Cloudflare workerd execution, Wrangler bundling or actual account deployment.
  Dependency download was unavailable in this build environment, so npm install
  and wrangler deploy were not run. The package pins Wrangler in package.json.
- Native unrestricted browser WebSockets or school/home network reachability.
  The container Chromium is managed-policy blocked, hence the test-only bridge.
- Public internet round-trip delay, region placement, throughput or latency under load.
  Test transport timings are local and must not be described as real-world ping.
- Natural completion of every stage/achievement, full lengthy Quickplay rematch
  sessions, long spectator sessions, all reconnect timing races, or migration of
  an existing public account database. This is a new, isolated installation.
- Real platform hibernation/resumption, durable storage persistence across real
  Cloudflare deploys, free-tier capacity, billing totals, or full abuse resistance.
- Native Safari/iOS behavior, all mobile input gestures, and hundred-player scale.
- Cryptographic/security audit or tamper-proof scoring. Host browser physics and
  client-reported solo records remain trusted for this casual game.
