RIBBIT RACE FRIENDS — POLISH 66 / VERSION 1.7.53

REPLAY CONTROLS
- Space tapped briefly toggles play/pause.
- Hold Space for at least one second to temporarily fast-forward at 2x.
- When initially paused, the fast-forward scrubs silently and returns to paused.
- The replay HUD's top-right X uses a chunkier inset pixel-art shape.

ACCOUNT / STUDY
- New VOCAB LIST entry in ACCOUNT & LANGUAGE. Search available English/Spanish terms, refresh from cloud, or open flashcards.
- Flashcards redesigned as stacked pixel-art cards inspired by the supplied reference.
- Tap/Space/Enter flips with a 3D turn. Swipe left marks WRONG; swipe right marks RIGHT. Keyboard 1/2 also grade cards.
- Cards marked wrong return in subsequent review passes until graded correct.
- Pencil opens a notes editor on the back of the card. Hover a card to read its saved note; notes are stored in this browser under the current account name.
- Original bookmark stars may still be toggled, but bookmarks no longer determine study review.
- Layout supports desktop and mobile landscape dimensions.

PACKAGE CLEANUP
- Excludes all obsolete UPDATE_NOTE_POLISH_* files, DESIGN_PREVIEWS, and development regression tests.
- Includes /public for serving, /src for the Cloudflare Worker, /client for editable game sources, /scripts for the build, package.json, wrangler.jsonc, replay compatibility notes and this release note.
- The 615-test development regression suite passed before packaging. Tests are kept out of the deployment ZIP to reduce file count.

DEPLOYMENT: Replace the GitHub repository files with this ZIP's contents. Build with npm run build; deploy with npm run deploy if using Wrangler. No database migration or code.gs change is required.
